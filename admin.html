📋 How to publish your updates

  1. Make your changes below. Click Save Changes to keep a draft in this browser.
  2. Click Download menu.json to save the updated menu file to your device.
  3. Open your website repository on GitHub and go to the data folder.
  4. Choose Add file → Upload files, select the downloaded menu.json, and replace the existing file.
  5. Click Commit changes. Your website will update within a few minutes.
